# 📚 AI Flashcard Generator

An AI-powered study assistant that transforms lesson content into structured learning materials such as flashcards, key concepts, and revision notes.

Built using HTML, CSS, JavaScript, the HTML5UP Escape Velocity template, and the Groq API for AI-powered content generation.

## 📖 How It Works

1. Paste lesson notes or study material into the input area.
2. Click **Generate Study Material**.
3. The content is sent to the Groq AI model.
4. The AI processes the lesson content and generates:
   - Flashcards
   - Key Concepts
   - Revision Notes
5. Results are displayed instantly on the webpage.

## ⚙️ Setup Instructions

### Clone Repository

```bash
git clone https://github.com/yourusername/ai-flashcard-generator.git
```

### Open Project

Open the project folder in Visual Studio Code.

### Configure API Key

Inside `script.js`, replace:

```javascript
Bearer YOUR_GROQ_API_KEY
```

with:

```javascript
Bearer YOUR_ACTUAL_GROQ_API_KEY
```

### Run Locally

Launch the project using Live Server or any local web server.
